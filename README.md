1. 핵심 수치: `index.html` 안 `<!-- [수정] -->` 주석 위치의 숫자만 교체
2. 대표 콘텐츠 썸네일: `<img class="cover-img" src="images/파일명.jpg" ...>` 처럼 `src` 추가 (없으면 에디토리얼 커버 표시)
3. 협업 이력: `.log li` 복사 후 이름·진행 형태 태그 수정
4. 단가: `.plan .price .n` 값 수정
